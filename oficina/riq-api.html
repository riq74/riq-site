Estudo de caso

Riq API

Uma extensão para testar interface quando a API ainda não responde do jeito que a tela precisa. A resposta simulada fica na sessão de quem instalou.

O problema

Montar uma tela depende de respostas que às vezes não existem, mudam ou custam caro de repetir. Queria ver o que a página recebe e trocar essa resposta por um exemplo controlado, sem alterar o servidor.

O que ficou de pé

A Riq API é uma extensão Manifest V3. No popup, a pessoa organiza regras em grupos, inspeciona o tráfego da página em teste e define a resposta simulada. As regras ficam no armazenamento local do navegador.

O painel também aceita ajuda para redigir uma regra, com validação do que foi escrito antes de guardar. A interface tem mais de um idioma. A versão publicada nesta página é a 0.3.0.

Como está feito

  • Extensão Chromium, Manifest V3
  • Popup em React e TypeScript
  • Regras conferidas por esquema antes de entrar em uso
  • Testes de unidade e uma passagem de fumaça da interface

O que continua com a pessoa

Quem testa liga a regra, olha a resposta e desliga quando a tela já foi conferida. A extensão serve a sessão de desenvolvimento. Ela não publica dados e não substitui o contrato real da API.

Esta página conta a peça. A extensão não está na loja nem publicada neste site.
